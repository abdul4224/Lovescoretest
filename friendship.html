How Friendship Score Works

Friendship Score Test turns two names into a single, fun compatibility number between 0% and 100%. There's no sign-up, no email address, and no data sent anywhere — every calculation happens right inside your browser using JavaScript, and the page never contacts a server with the names you type.

Behind the scenes, the tool reads the letters of both names and converts them into numeric values, combining them using a small set of mathematical rules — including letter positions, name length, and a bit of controlled randomness seeded by the names themselves — to produce a repeatable score. Enter the exact same two names again and you'll get the exact same result every time, which makes it fun to compare different friend pairs.

1. Type in two names

Add your name and a friend's name into the fields above.

2. The algorithm runs instantly

Each letter is converted into a value, combined across both names, and reduced to a single percentage — all client-side, in milliseconds.

3. See your animated score

A heart meter and progress bar fill up to your Friendship Score, along with a short, playful message.

4. Share the result

Send your score straight to Facebook, WhatsApp, or Twitter (X) and challenge your friend group.

This is a novelty tool built purely for entertainment — a lighthearted way to spark conversation with friends, not a scientific measure of how strong a real friendship is. Real friendship depends on trust, shared time, and effort, none of which a name-based algorithm can measure.

Frequently Asked Questions

How does the Friendship Score calculator work?

The tool takes both names, runs them through a deterministic character-based algorithm, and converts the result into a percentage between 0 and 100. The same two names will always produce the same score.

Is the Friendship Score scientifically accurate?

No. This is a fun, entertainment-only tool. It does not use any real psychological assessment or personal data.

Is my data stored anywhere?

No. Everything runs directly in your browser. The names you type are never sent to a server or saved anywhere.

Can I test group friendships too?

This version tests two names at a time, but you can run it multiple times with different pairs to compare a whole friend group.

Can I share my Friendship Score with friends?

Yes. After your score appears, you can share it directly to Facebook, WhatsApp, or Twitter (X) using the share buttons below the result.

Friendship Score Test is a free entertainment tool. Results are generated for fun only and are not a scientific measure of friendship.
