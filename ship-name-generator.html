    What is a ship name?

    A ship name is a single nickname made by merging two people's names into one word. The term comes from "relationship", and it spread through fan communities and entertainment press before becoming an everyday way to refer to a couple. The best-known examples are celebrity pairs: Bennifer for Ben Affleck and Jennifer Lopez, Kimye for Kim Kardashian and Kanye West, and Brangelina for Brad Pitt and Angelina Jolie.

    They work because they keep both names recognisable while still sounding like one word you could actually say out loud. That's the balance this generator tries to hit.

    How this generator works

    The tool splits each name at the points where vowel sounds meet consonant sounds, since those are the natural seams in a word. It then joins the start of one name to the end of the other in every valid combination, in both directions, and scores each result on three things: whether the length sits in a comfortable range, whether it's pronounceable (long runs of consonants or vowels get marked down), and whether both original names are still recognisable in the blend. The highest-scoring options are shown first.

    Picking one that actually sticks

    • Say it out loud a few times. If it's awkward to pronounce, it won't get used.
    • Shorter usually wins. Five to eight letters tends to feel natural.
    • Check it doesn't accidentally spell something unfortunate.
    • If two options are close, go with the one that sounds more like a real name.

    Frequently Asked Questions

    What is a ship name?

    A ship name is a single nickname made by blending two people's names together. The word comes from "relationship". Well-known examples include Bennifer for Ben Affleck and Jennifer Lopez, and Kimye for Kim Kardashian and Kanye West.

    How does this generator blend the names?

    It splits each name at the boundaries between vowel and consonant sounds, then joins the start of one name to the end of the other in every valid combination. Each result is scored on length, how easy it is to pronounce, and whether both names stay recognisable, and the best-scoring blends are shown first.

    Why do I get several options instead of one?

    There is no single correct blend for any pair of names. The tool shows the strongest options it found so you can pick whichever one sounds best to you.

    Are the names I type stored anywhere?

    No. The blending runs entirely in your browser. Nothing you type is sent to a server or saved.

    Will the same two names always give the same results?

    Yes. The tool is fully deterministic, so the same two names always produce the same list in the same order.
